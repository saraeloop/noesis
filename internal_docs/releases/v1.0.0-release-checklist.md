# Noēsis v1.0.0 Release Checklist

This is the **minimal ritual** before tagging `v1.0.0`.  
Everything else (SBOMs, OTLP, policy audits, fancy TUI) is 1.1+.

---

## 0. ADRs & Roadmap

- [x] **ADR-001 — Runtime Session**
  - [x] ADR-001 marked **Accepted** and matches current code.
  - [x] `NoesisSession` / `SessionBuilder` behavior in docs is consistent with the implementation.
- [x] **ADR-002 / ADR-003 / ADR-004**
  - [x] ADR text reflects the actual implementation (canonical serialization, determinism primitives, artifact layout).
  - [x] ADR-004 clearly distinguishes:
    - **substrate** (canonical serialization + determinism plumbing),
    - **drill** (replay comparator + golden),
    - ADR-006 (future drift tooling).
- [ ] **ADR-005 — Prompt Provenance**
  - [ ] Either clearly marked **Proposed / Experimental** (if not shipped),  
  - [ ] Or documented as **v0.1, optional & behind feature flag** (if partially implemented).

## 2. Determinism & artifacts (ADR-002 / ADR-004)

- [x] Run the full test suite: `uv run python -m pytest`.
- [x] Ensure `tests/runtime/test_determinism.py` and `tests/runtime/test_serialization.py` are green.
- [x] Run a minimal-mode episode and a meta/governed episode; keep both run dirs.
- [x] Run `noesis artifacts verify <episode_dir>` on each and confirm `manifest.json` passes.

### 2.1 Replay comparator (ADR-004 drill)

- [x] **Implement replay helper**:
  - [x] `noesis diagnostics replay <run_a> <run_b>` (or equivalent) exists and works.
  - [x] Reuse the normalization logic from `tests/runtime/test_determinism.py` to:
    - [x] compare `summary.json` bytes,
    - [x] normalize `state.json` / `manifest.json`,
    - [x] structurally compare `events.jsonl`.
- [x] **Wire a deterministic golden**:
  - [x] Tiny scenario that runs twice under `DeterminismConfig`.
  - [x] Run dirs stored under `tests/golden/` (e.g. `tests/golden/determinism/`).
  - [x] CI asserts the comparator reports **NO DRIFT**.

### 2.2 Manual sanity

- [x] Use the replay comparator on a deterministic scenario:
  - [x] `noesis diagnostics replay <run_a> <run_b>` (or equivalent),
  - [x] Confirm it reports **NO DRIFT** for summary/state/manifest/events.
- [x] Manually inspect one `events.jsonl` + `state.json` to verify phases, lineage, and IDs look sane.
