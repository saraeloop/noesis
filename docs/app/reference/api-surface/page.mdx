# Supported imports

These modules are part of the **supported** Python surface. Anything outside
this list (for example `noesis.domain.*` or `noesis.runtime._*`) is an internal
detail and can change without notice.

<Callout type="warning" emoji="⚠️">
Avoid importing from `noesis.domain.*`, `noesis.usecases.*`, `noesis.infrastructure.*`,
`noesis.interfaces.*`, or any module whose name starts with an underscore. Those are
internal details and will change.
</Callout>

<Callout type="info" emoji="🗓️">
Deprecated shims (`noesis.summary.load`, `noesis.events.start_event`, `noesis.state.store.EpisodeStore`,
etc.) were removed in **v0.9.0**. Use `noesis migrate` to rewrite callsites automatically or
temporarily set `NOESIS_LEGACY_SHIMS=1` to finish the migration.
</Callout>

## Migration guide

| --- | --- | --- |

| `from noesis.runtime._summary import finalize_summary` | `from noesis.summary import finalize` | v0.9.0 |

## Things the codemod can’t fix

Star-imports and dynamically generated callsites need a quick manual edit. For example:

```python filename="before.py"
from noesis.summary import *
episode_summary = load("ep")  # legacy shim
```

```python filename="after.py"
from noesis.summary import read
episode_summary = read("ep")
# then re-run: noesis migrate .
```

Re-run `noesis migrate` afterwards to confirm the workspace is clean.

## Module quick reference

| Module | Purpose |
| --- | --- |
| `noesis` | Entry points (`run`, `solve`, `set`, `get`, `summary`, `events`, …) plus intuition and direction helpers. |
| `noesis.io` | Read-only helpers for summaries, events, metrics, and run listings. |
| `noesis.events` | Emit cognitive-loop events (observe/interpret/plan/act/reflect/learn). |
| `noesis.summary` | Finalize summaries and emit derived insight metrics. |
| `noesis.episode` | Episode manifest API (`EpisodeIndex`, `EpisodeIndexPort`, `EpisodeRecord`). |
| `noesis.context` | Runtime context tooling (`RuntimeContext`, `create_runtime_context`, config accessors). |
| `noesis.ports` | Public port protocols for custom adapters and infrastructure bindings. |
| `noesis.trace` | Trace schema helpers (`read_events`, `write_event`, `write_cognitive_event`, `read_summary`). |
| `noesis.artifacts` | Manifest utilities (`verify_manifest`, `load_manifest`, HMAC signing helpers). |
| `noesis.learn` / `noesis.insight` | Learning and insight programmatic helpers. |
| `noesis.diagnostics` | Run comparison and drift detection (`compare_runs`, `DriftResult`, `DriftMismatch`). |
| `noesis.adapters.*` | Reference adapters (LangGraph, CrewAI, etc.). Treat as examples. |
| `noesis.session` | Session construction and management (`SessionBuilder`, `NoesisSession`, `DefaultSessionProvider`). |
| `noesis.determinism` | Deterministic clock and RNG helpers (`DeterministicClock`, `DeterministicRNG`). |

<Callout type="info" emoji="🧠">
Stick to the root facade for orchestration (`ns.run`, `ns.solve`) and the module surfaces for everything else.
Reserve `noesis.io.*` for advanced read-only tooling; the mainstream path is `ns.summary.read`, `ns.events.read`,
and `noesis.learn.emit` for post-run learning hooks.
</Callout>

```python filename="python"
# --- Core happy path ---------------------------------------------------------
import noesis as ns

episode_id = ns.run("Draft weekly update", intuition=False)
metrics = ns.summary.read(episode_id)["metrics"]
print(metrics["success"])

# --- Solving with a custom graph + capturing events --------------------------
from pathlib import Path

episode_id = ns.solve(
    "Generate release notes",
    using=lambda: Path("flows/release_notes.py"),
    intuition=True,
)

for ev in ns.events.read(episode_id):
    print(ev["phase"], ev["payload"])

# --- Working with the runtime context facade ---------------------------------
from noesis import context

ctx = context.create_runtime_context()
ctx.register("memory", provider=my_memory_port, api="memory/1.0")
context.set_context(ctx)

snapshot = context.get_config_snapshot()
print(snapshot)

# --- Finalizing summaries in backfills ---------------------------------------
from pathlib import Path
from noesis import summary

summary.finalize(
    run_dir=Path("./runs/demo"),
    episode_id="ep_demo",
    task="Backfill summary",
    seed=0,
    started_at="2025-01-01T00:00:00Z",
    intuition_enabled=False,
    intuition_mode=None,
    using_label="core.minimal",
    tags={},
    intuition=None,
    schema_version="1.2.0",
    config=context.get_config_snapshot(),
    ports=ctx.list_ports(),
)
```
