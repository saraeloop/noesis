# CLI reference

The CLI is installed with the package (entry point `noesis`). You can run it via `uv run noesis …` or install globally with `uv tool install .`.

## Commands

| Command | Description |
| ------- | ----------- |
| `noesis run "task"` | Execute a baseline episode. |
| `noesis solve "task" --using react` | Run via an adapter registered as `react`. |
| `noesis list --limit 5` | List recent episodes (table format). |
| `noesis list -j` | Output recent episodes as JSON (machine-friendly). |
| `noesis events EP_ID` | Stream events for an episode. |
| `noesis insight EP_ID` | Fetch computed insight metrics as JSON. |
| `noesis show EP_ID` | Display episode summary (friendly view). |

## Useful flags

- `--adapter` — Select which adapter to run against (`baseline` is default).
- `--intuition Guardrails` — Attach an intuition policy class for interventions/vetoes.
- `--phase direction` — Filter events by phase when using `noesis events`.
- `--follow` — Tail events or insight output continuously.
- `--limit N` — Cap list responses to `N` episodes.

```bash
# Tail direction events for the latest run
noesis events $(noesis list -j | jq -r '.[0].episode_id') \
  --phase direction \
  --follow
```

<Callout type="info" emoji="🔧">
All commands respect configuration set via <code>noesis set</code> or environment variables (runs directory, adapter registry, thresholds).
</Callout>
