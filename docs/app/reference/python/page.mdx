# Python API

Install Noēsis with `uv add noesis` or `pip install noesis`. Import the module as `import noesis as ns`.

## Core functions

| Function | Description |
| -------- | ----------- |
| `ns.run(goal, *, intuition=False, **kwargs)` | Execute a baseline episode without an adapter. Call as `ns.run("Draft update")`. |
| `ns.solve(task, *, using, intuition=False, **kwargs)` | Run through an adapter (e.g. LangGraph) registered under `using`. |
| `ns.summary.read(episode_id)` | Load summary JSON including metrics and insight. |
| `ns.events.read(episode_id)` | Load event stream (optionally filtered by phase). |
| `ns.list_runs(limit=20)` | Return recent episodes with metadata. |
| `ns.last()` | Convenience helper to fetch the most recent episode ID. |
| `ns.set(**config)` | Override global config (runs dir, thresholds, adapters, etc.). |

## Intuition helpers

- `noesis.DirectedIntuition`: base class for policies that can `hint`, `intervene`, or `veto`.
- `noesis.NoesisVeto`: exception raised when a policy vetoes an episode.
- `noesis.intuition.Policy`: low-level base class if you prefer full control.

```python
import noesis as ns


class Guardrails(ns.DirectedIntuition):
    def advise(self, state):
        if "wire transfer" in state["task"].lower():
            return self.veto(
                advice="Escalate to manual review.",
                rationale="Financial compliance"
            )


ep = ns.solve("Send a wire transfer", using="react", intuition=Guardrails())
summary = ns.summary.read(ep)
```

## Insight utilities

- `noesis.domain.faculties.insight.compute_metrics(events)` — compute metrics from a sequence of events (experimental).
- Legacy helpers under `noesis.insight.*` are deprecated; import from the `noesis.domain.faculties.insight` package instead.
