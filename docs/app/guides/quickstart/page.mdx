# Quickstart

This walkthrough gets you from zero to inspecting deterministic insight metrics with the CLI.

## Requirements

- Python 3.11+ with <code>uv</code> installed
- Access to an LLM provider supported by your adapters (e.g. <code>OPENAI_API_KEY</code>)

<Callout type="warning" emoji="⚙️">
Set any adapter-specific environment variables (model keys, endpoints) before you run commands. Noēsis reads them at runtime.
</Callout>

<Steps>

### 1. Install the package

```bash filename="terminal"
uv add noesis
```

You can also run from source with <code>uv tool install .</code> inside the repo.

### 2. Run a baseline episode

```bash filename="terminal"
uv run noesis run "hello world"
```

This executes the default baseline adapter and returns an episode ID (`ep_*`).

### 3. List recent episodes

```bash filename="terminal"
uv run noesis list --limit 5
```

Confirm your episode appears with timestamps and status. Use `-j` for JSON output when scripting.

### 4. Capture insight

```bash filename="terminal"
uv run noesis insight ep_abc123
```

Replace `ep_abc123` with your episode ID. The output is a machine-readable JSON blob that includes latencies,
veto counts, and any custom metrics you configured.

</Steps>
