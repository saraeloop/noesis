# Cognitive loop

When verbs are enabled, every episode emits a traceable spine that turns opaque reasoning into an auditable loop.

```text
[observe] -> [interpret] -> [plan] -> [act] -> [reflect] -> [learn]
```

## Instrumentation at v0.7.0

Beginning with **v0.7.0**, each verb is wrapped by the runtime clock and lineage tracker:

- `events.jsonl` entries now include `metrics.duration_ms`, `metrics.started_at`, and `metrics.completed_at`.
- Every event carries a `caused_by` UUID so you can reconstruct the full reasoning chain.
- Meta-phase hooks (`before_phase` / `after_phase`) let governance code audit or veto decisions without touching core orchestration.

This instrumentation lives in:

- `noesis/domain/state/cognitive.py` — `CognitiveVerb`, `CognitiveEvent`, and `LineageTracker`.
- `noesis/runtime/clock.py` — high-resolution timers for each phase.
- `noesis/usecases/hooks/meta_phase.py` — extension points for governance and insight.
- `noesis/usecases/episode_runner.py` — orchestrates the loop, emits enriched events, and enforces learn-phase payloads.

### Reading the new event shape

```json
{
  "id": "7d3d...f84",
  "phase": "plan",
  "payload": {"steps": ["detect:Collect context", "..."]},
  "metrics": {"started_at": "...Z", "completed_at": "...Z", "duration_ms": 12.7},
  "caused_by": "5c12...0a9"
}
```

Use `noesis diagnostics events --episode <id>` to inspect metrics or compute lineage coverage.

## observe
Captures the raw task and tags at the moment an episode starts so you can confirm the exact scope the agent perceived.

## interpret
Summarises the signals the policy or intuition layer noticed (e.g. risky files, high-value hints) before any plan is locked in.

## plan
Records the selected steps (whether that is a trivial single adapter hop or a richer graph) so you can compare intent versus action.

## act
Logs every tool or adapter invocation with inputs and outcomes, giving you a measurable execution history instead of guesswork.

## reflect
Evaluates what actually happened against expectations, including success flags and reasons that your dashboards can alert on.

## learn
Optionally captures follow-up updates (notes, caches, memories) so the next run can inherit lessons without scraping logs.
